# Checkpoint — Blog de Games

Blog acadêmico sobre games, desenvolvido apenas com HTML, CSS e JavaScript básico.

## Arquivos

- `index.html` — página Home, resumo do blog e conteúdos de destaque.
- `noticias.html`, `lancamentos.html`, `reviews.html`, `dicas.html` — páginas de conteúdo.
- `contato.html` — página de contato com formulário demonstrativo.
- `css/style.css` — estilos do projeto.
- `js/script.js` — menu mobile, ano automático e confirmação do formulário.

## Como publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie todos os arquivos mantendo as pastas `css` e `js`.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione `Deploy from a branch`, a branch `main` e a pasta `/ (root)`.
5. Copie o endereço gerado para o PDF da atividade.

## Antes de entregar

Substitua no PDF os campos de nome e matrícula pelos dados dos integrantes em ordem alfabética. Inclua o link do repositório GitHub e o link publicado pelo GitHub Pages.
