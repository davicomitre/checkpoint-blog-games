# Checkpoint — Blog de Games

Blog acadêmico sobre games, desenvolvido apenas com HTML, CSS e JavaScript básico.

## Arquivos

- `index.html` — página Home, resumo do blog e conteúdos de destaque.
- `noticias.html`, `lancamentos.html`, `reviews.html`, `dicas.html` — páginas de conteúdo.
- `contato.html` — página de contato com formulário demonstrativo.
- `css/style.css` — estilos do projeto.
- `js/script.js` — menu mobile, ano automático e confirmação do formulário.
